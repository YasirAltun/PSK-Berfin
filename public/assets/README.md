# Assets Klasörü

Bu klasöre kendi dosyalarınızı ekleyebilirsiniz:

## logo/
- `logo.png` — Ana logo (koyu arka plan için)
- `logo-light.png` — Açık arka plan için logo

## images/
- `psikolog.jpg` — Psikolog fotoğrafı (önerilen boyut: 480x600px)
  Hero ve Hakkımda bölümlerinde kullanılır.
  Eklenince `src/config/siteConfig.js` içindeki `about.photo` değeri otomatik olarak devreye girer.

## icons/
- `favicon.svg` veya `favicon.ico` — Tarayıcı sekmesi ikonu
  `index.html` içinde referans verilmiştir.

> Fotoğraf veya logo ekledikten sonra sayfayı yenileyin — değişiklikler anında görünür.
